What NUMPA does

Two engines built to work together, not around each other

Everything below feeds the same four-stage workflow — nothing here is a bolt-on tool.

Smart Data Cleaning

Fix what's wrong, on your terms

A visual pipeline builder, not a black-box "auto-clean" button. Every operation is visible, configurable, and reversible before you commit.

🧩

Ten operation categories

Missing values, encoding, scaling, outliers, duplicates, feature selection, data types, text cleaning, round & clip, renaming.

👁

Preview before you commit

See the effect of a step on your data before it runs, wherever a preview is feasible.

↺

Undo, redo, reset

Reorder or remove steps freely while you're still building the pipeline.

📜

Full execution history

Every run records what changed, on which columns, with before/after measurements.

ML Readiness Assessment

Know why, not just that

A deterministic, explainable score that adapts to your task and intended algorithm — with critical risks that never disappear just because the overall number looks good.

◎

Task-aware scoring

Classification, regression, time-series forecasting, and clustering each run their own relevant checks.

⚙

Algorithm-aware checks

Tree-based, linear, and distance-based models have different preparation needs — NUMPA accounts for that.

⚠

Leakage detection

Target, temporal, group, and cross-split leakage risks are flagged as confirmed, suspected, or unknown.

✓

Assessment coverage

You always see what was checked, what was skipped, and what couldn't be evaluated.

Four supported ML tasks

Each with its own relevant checks — no generic one-size-fits-all scoring.

Classification

Target availability, class distribution, missing labels, validation strategy.

Regression

Target validity, distributions, feature suitability, leakage risk.

Forecasting

Timestamp quality, chronological consistency, gaps, forecast horizon.

Clustering

Feature relevance, scaling, categorical handling — no target required.

Seven scoring dimensions

Configurable weights — these are the starting defaults.
